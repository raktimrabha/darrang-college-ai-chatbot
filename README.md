# Darrang College AI Admission Assistant

An AI-powered helpdesk and admission assistant for Darrang College. This project helps students get instant answers about admissions, courses, fees, exams, and campus life.

## Features
- **Instant Answers**: Get immediate responses to queries about the college.
- **AI-Powered**: Uses AI to understand and respond to student inquiries accurately.
- **Modern UI**: Built with React, Tailwind CSS, and a clean, accessible user interface.

## Tech Stack
- **Frontend Framework**: React with Vite
- **Routing**: TanStack React Router
- **Styling**: Tailwind CSS & shadcn/ui components
- **Language**: TypeScript

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

## Setup & Deployment
Make sure to configure your environment variables for any AI or backend services as needed before running the production build.
